# Knowledge Pack 記載規約(テンプレート)

各診療科ファイルは以下の16節構成を基本とする。節の順序・名称は変えない(機械抽出の前提)。

1. 収益構造 / 2. 主な患者導線 / 3. 頻出する基本診療料 / 4. 頻出する検査 / 5. 頻出する処置 /
6. 頻出する手術 / 7. 頻出する管理料 / 8. 頻出する加算 / 9. 主要な施設基準 / 10. 算定上の注意 /
11. 併算定で注意すべき項目 / 12. 典型的な診療パターン / 13. 経営上重要な診療報酬 /
14. 令和8年度改定ポイント / 15. 疑義解釈上の重要論点 / 16. 参照資料

## 記載ラベル(必須)

すべての記述は、文頭または節頭に次のいずれかのラベルを付ける。

- **[確定]** — 一次資料の実物で照合済み。必ず `根拠:` に documents.id とページを併記する
- **[一般整理]** — 診療報酬の具体的な点数・要件に踏み込まない、診療科運営の一般的な構造の整理。一次資料を要しないが、断定は避ける
- **[未検証]** — 項目名・論点として挙げるが、内容(点数・要件・可否)は一次資料で未照合。解決先の資料を `解決先:` に書く

## 禁止事項

- ラベルなしで診療報酬の点数・算定要件・併算定可否を書くこと
- 旧年度(令和6年度以前)の知識で[確定]を名乗ること
- 「おそらく」「一般的には〜点」のような推測点数

## 更新手順

原典取得(fetch_sources.mjs)→該当箇所の照合→[未検証]を[確定]へ昇格、`根拠:` を付記。
昇格させた事実は data/kb/{rev}/ の対応テーブル(items等)にも登録し、KBとPackの二重管理のズレを validate と目視で防ぐ。
