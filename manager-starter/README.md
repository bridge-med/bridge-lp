# 医療管理職スターター(仮称) — manager-starter/

医療専門職(看護師・リハビリ職・医療事務・訪問看護など)から**初めて管理職になった人**のための実務サービス。
中心メッセージは「臨床は分かる。でも、管理職の仕事は誰にも教わっていない。」。
無料テンプレート・記事・セルフチェック → スターターパック(単品販売) → 会員/法人プラン、と段階的に発展させるMVP。

ブランド名は仮称。**`manager-starter/data/site.mjs` の `SITE.name` 以外にハードコードしない。**

## medops との棲み分け(PM承認 2026-07-18)

- **医療管理実務ライブラリ(medops/)** = 施設運営・行政・バックオフィス実務(統合・管理医師変更・施設基準・事務長業務)
- **医療管理職スターター(本サイト)** = チーム運営・対人マネジメント(新任管理職・1on1・会議・業務分担・上司報告・採用教育)

同一役割の成果物を両サイトに複製しない。1on1は「初回(顔合わせ)専用=本サイト」/「定例の型=medops」、
業務分担は「15分書き出し版=本サイト」/「分担整理の本表=medops」と役割を分けている。
将来の統合判断は台帳の未決事項。

## 起動方法

静的サイトなのでビルド・サーバーは不要。ローカル確認は:

```
python3 -m http.server 8000   # リポジトリルートで実行
# → http://localhost:8000/manager-starter/
```

## 構造

```
manager-starter/
  data/              唯一の情報源(ES Modules。Node生成スクリプトとブラウザ両方が読む)
    site.mjs         ブランド名・価格・ナビ・計測イベント名・職種・管理職歴・形式
    categories.mjs   テーマ8種(絞り込み・記事分類用。カテゴリ詳細ページは持たない)
    templates.mjs    無料テンプレート(公開10)+パック収録20(status:'pack')
    articles.mjs     記事(公開5+第2弾予定5+下書き10)
    product.mjs      スターターパック(status 1操作で公開/保留切替)
    diagnosis.mjs    現在地チェック(12問・4領域・結果4種)
    professions.mjs  職種別ページ(第2弾で公開予定。現状全draft)
  assets/
    ms.css           デザインシステム(medopsをフォーク。トークンは憲法第22条の4系統)
    ms.js            ランタイム(テーマ/絞り込み/検索/コピー/問い合わせダイアログ/セルフチェック)
  index.html ほか    すべて生成物。手で編集しない

scripts/manager-starter/
  build.mjs          全HTMLを静的生成し、ルート sitemap.xml のマーカー区間を更新
  html.mjs           共通レイアウト・カード部品・JSON-LD
```

## コンテンツの追加・変更

1. `manager-starter/data/*.mjs` を編集(記事・テンプレ追加は1オブジェクト)
2. `node scripts/manager-starter/build.mjs` で全ページ再生成+sitemap更新
3. `node scripts/check-site.mjs` で機械検査
4. `ship` スキルに従って出荷

- 価格変更: `site.mjs` の `pricing` だけ
- 診断の質問変更: `diagnosis.mjs`(質問は areaId 4種に3問ずつ。結果は最低点領域で決まる)
- ブランド名変更: `site.mjs` の `name` → 再生成
- `status:'draft'` はページ生成・一覧表示なし(憲法第14条)。パックの公開保留も `product.mjs` の status 1箇所

## 設計判断のメモ

- **診断は断定しない** — 「あなたは◯◯タイプ」ではなく「いま整えると効きやすい領域」+今週やること3つ+道具の提示(第9条2号)。医学的診断でない旨と保存しない旨を明記。回答は端末内で完結
- **スターターパック** — 決済未実装のため「決済準備中」明示、CTAは「購入方法を問い合わせる」、JSON-LDにOfferなし(medops前例踏襲)。**実ファイル20点の整備が公開後の最優先タスク**
- **偽メトリクスなし** — DL数・評価・「人気順」は置かない(おすすめ順=priority)
- **検索** — ヘッダー検索 → templates/index.html?q= でテンプレ絞り込み+記事横断表示

## 第2弾(次の出荷)の予定

1. 記事5本の本文化(会議が長い理由/最初に見る数字/年上の部下/抱え込みサイン/退職相談)
2. 職種別ページ4枚(リハ=当事者、看護・訪看・事務=経営支援での伴走の立場を明記して執筆)
3. 法人向けページ(問い合わせはモック=BRIDGE communityへ)

## 販売開始までに必要な作業

1. パック実ファイル20点(Excel/Word)の作成
2. 決済(Stripe Payment Links が最小)+ **特定商取引法に基づく表記**(必須)
3. 法務3枚の専門家確認(**medopsの法務3枚と同一水準の仮文面。確認は両サイト分を1回で**)
4. 返金条件・更新版提供方法の確定

## 本番公開前に確認すべき事項

- `legal/` 3枚は仮文面(要専門家確認)
- 職種別ページの当事者性(リハ以外は伴走者の立場を明記) — PM申し送り
- BRIDGE本体 products 一覧・サムネイルへの掲載可否は社長判断
