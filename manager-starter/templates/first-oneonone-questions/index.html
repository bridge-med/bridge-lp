初めての1on1質問シート

着任後はじめての顔合わせ1on1専用。関係づくりと状況把握のための質問例。

バージョン 1.0 公開 2026/07/18 更新 2026/07/18

着任して最初の1on1は、定例の1on1とは目的が違います。評価でも課題解決でもなく、「相手を知り、自分を知ってもらい、話せる関係の入口を作る」のが目的です。このシートは初回専用の質問例です。定例の1on1の型(質問の順番と記録欄)は、姉妹サイト医療管理実務ライブラリの1on1シートと役割を分けています。

1人15〜20分。全部聞く必要はありません。各グループから1〜2個選び、相手が話し始めたらシートから離れて聞いてください。

最初に伝えること(質問の前に)
  • この面談の目的(評価ではなく、状況を知りたいこと)
  • 話した内容をどう扱うか(誰に共有するか・しないか)
  • 定期的に続けたいこと(頻度の希望も聞く)
相手を知る質問
  • これまでの経験と、いちばん長くやってきた業務を教えてください経歴書ではなく本人の言葉で
  • 得意なこと・任されるとうれしい仕事はありますか答えにくそうなら「逆に苦手な業務は」から
  • いまの業務量は、率直にどうですか多い/ちょうど/余裕がある、の3択で聞くと答えやすい
チームについて聞く質問
  • チームのやり方で、変えてほしくないことはありますか先に「守るもの」を聞くと本音が出やすい
  • 逆に、前から気になっていること・やりにくいことはありますか出てきたら課題一覧へ。その場で解決を約束しない
締めの質問
  • 私に期待すること・してほしくないことはありますか
  • 次回までに私が確認しておくことはありますか
面談後に記録すること(3行でよい)
  • 話された事実:
  • 本人の希望・気になったこと:
  • 自分の宿題と次回確認すること:

無料

登録なしで使えます。内容をコピーし、職場に合わせて編集してください。Excel・Word版のダウンロード提供は準備中です。
