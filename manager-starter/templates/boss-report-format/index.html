上司報告の基本フォーマット

状況・課題・対応・相談の4項目で、口頭でも文面でも使える報告の型と文例。

バージョン 1.0 公開 2026/07/18 更新 2026/07/18

上司への報告が長くなる、または遅れるのは、能力の問題ではなく型がないからです。このフォーマットは「状況・課題・対応・相談」の4項目に絞った報告の型です。週次の定例報告にも、トラブル時の緊急報告にも同じ型が使えます。

報告は「相談」から逆に組み立てると速くなります。上司に決めてほしいことを先に決め、それに必要な情報だけを前に置いてください。

4項目の型
  • 1. 状況チームの現状を2〜3行。数字があれば1つ添える(例: 今月の稼働は前月並み)
  • 2. 課題いま困っていること・これから困りそうなこと。多くても3つまで
  • 3. 対応自分がすでにやったこと・やる予定のこと。「対応済み」が上司の安心材料になる
  • 4. 相談上司に決めてほしいこと・力を借りたいこと。「報告のみ、相談なし」も立派な相談欄
週次報告の文例(そのまま編集して使う)
  • 【状況】今週は大きなトラブルなし。新人◯名は予定どおり研修中です。
  • 【課題】(1)◯曜日の人員が薄い状態が続いています (2)物品管理の担当が決まっていません。
  • 【対応】(1)は来月のシフトで調整予定。(2)は次回チーム会議で担当を決めます。
  • 【相談】(1)の恒常的な対応として、応援体制についてご相談したいです(10分)。
使い方のコツ
  • 毎週同じ曜日・同じ形式で出す(内容が薄い週も出す。ゼロ報告に価値がある)
  • 緊急報告も同じ4項目で。「状況→すでにやった対応→相談」の順が最短
  • 口頭報告のときも、この4項目をメモしてから行く

無料

登録なしで使えます。内容をコピーし、職場に合わせて編集してください。Excel・Word版のダウンロード提供は準備中です。
