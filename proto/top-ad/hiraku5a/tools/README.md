# 案A の止めた画像を撮り直す道具

案A は、立体が動かないとき(動きを減らす設定・WebGL なし・データ節約・立体に替わる前)だけ、ひらいた病院ぜんたいの止めた画像(`img/open-<時刻>-<sp|pc>.webp`)を使います。動きを減らす設定でなければ、町の止めた画像を病院へ寄せてから、この画像へ 0.25 秒で替えます(重ねたまま進めない)。町や病院の中(world.js・buildings.js・interiors.js)を変えたら撮り直します。

1. リポジトリのルートを `http://localhost:8097/` で配信する(例: `http-server . -p 8097 -s -c-1`。別の場所なら `BASE` で渡す)
2. 撮る(時刻 3 × スマホ・PC の 6 枚。透明の地の PNG)

   ```
   PW=/opt/node22/lib/node_modules/playwright/index.mjs OUT=<出力先> node capture-open.mjs
   ```
   出力の JSON は、道具の札の置き場(その道具の階の天井の切り口。画像の %: x, y)。`hiraku.js` の `BAND_SP`・`BAND_PC` に写す
3. webp にする(品質 82 くらい)。大きさは変えない(スマホ 786×1448・PC 1600×1000。`hiraku.js` の `OPEN_STILL` の w・h と同じ)

撮る見え方は live.js の capture の `cutaway` に足した引数で決める。立体の「ひらいた病院ぜんたい」(live.js の K1)と同じ見え方にそろえてある:
- `open5=1`: 屋根を残し、前の壁は外し(倒れて広場の下へ沈んだ後)、広場の弧は消す
- `el`: 見下ろす角(14°。屋根を残したまま、3階の奥のソファの人と道具が天井の板に隠れない角度)
- `dim`: まわりの建物を暗く(.3)
- `box=1`: 建物の箱で収める
- `fx0`〜`fy1`: 収める範囲(ページの上の見出しと下の入口を避ける。立体と同じ幅・高さ)

立体の見え方を見比べる引数(ページの URL に付ける): `el1=<度>`(ぜんたいを見る角度)・`turn=<度>`(横の面を見せる回し)・`wall=keep`(倒れた壁を沈めない。前の版の見え方)
