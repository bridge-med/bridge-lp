# v6 の止めた画像を撮り直す道具

v6 は、立体が動かないとき(WebGL なし・データ節約・立体に替わる前・低性能の端末・描く器を失ったとき)と、動きを減らす設定の畳んだ区画で、到着の画と同じ視点の「ひらいた病院ぜんたい」の止めた画像(`img/open-<時刻>-<sp|pc>.webp`)を使います。動きを減らす設定でなければ、町の絵を病院へ寄せてから(立体を止めた絵は 1.5 倍まで)、この画像へ 0.25 秒で替えます(重ねたまま進めない)。町や病院の中(world.js・buildings.js・interiors.js)や、到着の画の決め方(live.js の `arriveFrame`)を変えたら撮り直します。

1. リポジトリのルートを `http://localhost:8097/` で配信する(例: `http-server . -p 8097 -s -c-1`。別の場所なら `BASE` で渡す)
2. 撮る(時刻 3 × スマホ・PC の 6 枚。透明の地の PNG)

   ```
   PW=/opt/node22/lib/node_modules/playwright/index.mjs OUT=<出力先> node capture-open.mjs
   ```
   出力の JSON は、道具の札の置き場(`band`。その道具の階の天井の前の切り口の上で、横は物が画面に映る位置。live.js の `bandAt`)、階の印(`marks.fl`。3F・2F・1F)、正面の地面の線(`marks.gy`)。どれも画像の %。`hiraku.js` の `STILL_SP`・`STILL_PC` に写す
3. webp にする(品質 82 くらい)。大きさは変えない(スマホ 786×1448・PC 1600×1000。`STILL_SP`・`STILL_PC` の w・h と同じ)

撮る見え方は live.js の capture の `cutaway&id=hospital&arrive=1` で決める。立体の到着の画と同じ式(`arriveFrame`)で、同じ大きさの画面(`cw`・`ch`。スマホ 393×724・PC 1440×900)の枠を求め、その2倍(PC は 1600/1440 倍)で描く:
- 視点: turn −16°・el 11°(案B と同じ。`turn`・`el` で変えられる)
- 屋根を残し、前の壁は外し(沈んだ後)、広場の弧は消す。外枠の太い切り口つき
- 町は暗くせず、主棟のほかをその時刻の空気の色へ(`uAir` = 1)。正面の広場には人を立たせない
- 一個の物として切り出す(live.js の `mainAir`。立体の舞台と同じ): 主棟の外形に重なる物と 8px 以内に接する物のうち、手前の物と病院の主棟の外の部分(右の翼・救急口)は消し、奥と脇の物は空気の色へ .85 まで。夜は右の側面に月の光

## 案B と同じ視点で、病院の中だけを撮る(bview)

`bview.html` は、案B の断面の撮り方(`hiraku5b/sect.js` の capture: 視点 az −16°・el 11°・島の一切れ・枠)のまま、病院の中の形(interiors.js)だけを差し替えて撮る。病院の中の作りを、同じ枠で比べるため。

```
PW=/opt/node22/lib/node_modules/playwright/index.mjs node bview.mjs 'src=6&tod=night&w=786' out.png
```
`src=6`(既定。この試作の中)・`5a`(v5 の案A)・`5b`(案B そのもの)。

## 立体の見え方を見比べる引数(ページの URL に付ける)

`el1=<度>`(ぜんたいを見る角度。既定 11)・`turn=<度>`(横の面を見せる回し。既定 −16)・`wall=keep`(倒れた壁を沈めない)・`bare=1`(札と言葉を隠す)・`still=1`(動きを減らす設定と同じ畳んだ区画)・`slow=1`(低性能の端末と同じ、舞台を止めた画像で)・`perf=1`(左下に重さの表示)
