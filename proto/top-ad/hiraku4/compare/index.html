ひらく町 v4 — トップページ全体の再構成

最初の画面(町)はそのままに、その下を「同じ形の帯を6回」から、幕ごとに構図・縮尺・密度・視点の変わる流れに組み直しました。町の俯瞰 → 病院の正面の断面 → 言いかえ(触れる一場面)→ 道具の実際の画面2つ → 夕から夜の空と遠くの夜の島。29の道具すべてへは、町のパネルと Products から届きます。

v4 を開くv3(いま)を開く第2幕を昼の1枚で見る(比べる版)

1. 新旧の全ページ(縮めて1枚で)

v3 は、最初の大きな町と最後の夜の町の間を、同じ骨組みの帯が7本埋めていました(ページの長さの約65%)。v4 は、隣り合う幕の形が毎回違います。スマホのページは v3 より約1画面短くなりました。

2. 帯を残す案と、組み直す案の比較

designer が、帯を残す案(A)と幕で組み直す案(B′)を同じ縮尺で比べ、B′ を推奨しました。A は帯の大きさや余白を変えても「建物の数だけ同じ骨組み」が残り、最初の画面と下の体験の差という課題を解きません。

3. 新しいページの構成

  1. 第1幕 町との出会い いまの最初の画面(立体・動く・訪問者の時刻)。下の端の色から紙へ、線や帯を置かずにつなぐ。
  2. 第2幕 いつもの職場の一日 病院を正面から切った断面の止めた絵(図面の視点・静か)。3階は昼、2階と1階は夕方の光。3つの道具の札。
  3. 言いかえ 「いつもの仕事を外の言葉で言うと」。6つの仕事から選ぶと、言いかえが大きく入れ替わる(ページの中で触れられる唯一の体験)。
  4. 第3幕 道具との出会い 経験の棚卸し(縦長の画面を左に大きく)と、クリニックタウン3D(6日目の相談の画面を正方形で右に)。押すと、その画面が広がって道具になる。続けて「すべての道具を一覧で見る 29点」。
  5. 終幕 夜の町 紙から夕、夜へ移る止まった空。遠くに夜の島。明朝の一文、運営者の一行、出口4つ、「見るだけで帰っても、それで十分です。」

4. 最初の画面のほかの見せ場

第2幕 いつもの職場の一日(病院の断面)

町の立体から、病院を正面から切った断面を撮りました(主棟だけ・前の壁を外し屋根は残す)。最初の町が引きの俯瞰なら、ここは正面の立面図です。中の人は時刻で入れ替わる本物のシミュレーションで、3階は昼、2階と1階は夕方の光を継ぎました(比べるための昼の1枚は ?day=1)。札は道具の名前と Products の一行だけで、導入先や効果は書いていません。

言いかえ(触れる一場面)と、道具の実際の画面

言いかえは、第2幕の「いつもの仕事」を外の言葉へ渡す一場面です。道具は本番トップの代表作の2つに絞り、形の違う実際の画面を大きく見せます(加工しない。切り出しだけ)。クリニックタウン3D は、ゲームを実際に6日目まで進めて撮りました。

終幕 夜の町

第3幕のあと、紙から夕方、夜へ移る空を止まったまま見せ、遠くに夜の島を置きました。夜はページの中でここ1か所だけです。文字はすべて夜の単色の上に置いています。

5. スマホのスクロール体験

スマホでは、第2幕の札を断面の各部屋の左上に置き(道具名だけ)、文字だけの面が2つ続かないようにしました。画面を止めて場面を送る演出や、スクロールの乗っ取りはしていません。

6. 性能とアクセシビリティ

アクセシビリティ・JS なし・WebGL なし

  • キーボードの順は読む順(第2幕の札 → 言いかえ → 第3幕 → 終幕 → フッター)。フォーカスの輪は紙の上で藍、夜の上で生成り
  • 押せるものは 44px 以上(第2幕の札: PC は 44px、スマホは当たり判定 44px)
  • 文字のコントラストは紙と夜で 4.5:1 以上(夜の時刻は、第2幕の見出しを夜から紙へ移る帯の下へ下げて直した)
  • 動きを減らす設定: 言いかえの下線も、画面が広がる動きも止まる。町は止めた画像
  • JS なし: 建物の行き先は Products の用途の節・考え方・運営者。29件の一覧を出す(Products の29件と一致)
  • WebGL なし: 町のパネル(止めた断面の画像)から29件すべてへ
  • 320〜1920px で横にはみ出さない
