# P3「3Dをやめる」— 選ぶ瞬間(仮題)

- 成果物: `p3.mp4`(15.0 秒・30fps・1920×1080・H.264・無音)、止め絵 `p3-t{0.0,2.5,5.0,8.0,11.0,14.0}.png`(1920×1080)
- 作り方: リポジトリを localhost で配り、実物のページを Playwright(Chromium)で開き、製品自身の操作(クリック・入力・切替)で状態を進める。ページの時計(setTimeout・rAF・Date・CSS の遷移・SVG のアニメーション)を仮想の時計に差し替えて 1 コマずつ進め、CDP の `Page.captureScreenshot` の clip と scale で任意の範囲を任意の倍率で撮る。拡大は画像の引き伸ばしではなく、ページがその倍率で描き直した画素(40 倍でも文字と線はにじまない)。速い寄り・引きだけ、10〜14 枚の副コマを平均して 180° シャッター相当のぶれを付ける。WebGL のあるクリニックタウン3D だけ SwiftShader で描く
- 最後の署名(マーク・BRIDGE・EXPAND CHOICES.)だけ BRIDGE の面(`card/index.html`。マークはサイトのロゴ(`shared/bridge.js` の MARK。コンセプトシートから起こした近似の曲線で、未決#7)と同じパス、色はライトのトークン、書体は Inter 500・字間 0.34em / 0.22em)
- 使っていないもの: 3D の空間、人物、端末の枠、浮いたカードと影、光彩・粒子・フレア、意味のない漂い(ケン・バーンズ)、線を引いて説明する語彙(PR #131)
- コード: `lib.mjs`(配信・ブラウザ)・`engine.mjs`(仮想時計・撮影・ぶれ)・`shots.mjs`(ショットごとの操作とカメラ)・`run.mjs`・`assemble.sh`・`job.sh`。コマは `frames/f5/`(`_all/` が通しの 450 コマ)
- 版: `rough1.mp4`(960×540 の最初の通し、着手から約 50 分)→ f1〜f5(1920)。f2 で選ぶ瞬間の連打を足し、f3 で結果の図を「現在地から引く」に変え、f4 で入力中のカーソルを常に見えるように、f5 で結果の画面からサイトのナビを外した。`p3.mp4` は f5

## 着想(5行)

1. 15秒のあいだ、主役は「選ぶ瞬間」だけ。印がつく・字が確定する・星がつく・方針を決める。どれも製品自身の操作で、画面の中心近くで起きる。
2. カメラは「寄り」と「引き」だけ。寄ると UI の部品は抽象的な形(輪と巨大な「人」、砂色の円、星、明朝の見出し)に見え、引くと実物の道具だと分かる。その落差を拍としてくりかえす。
3. 前半は夜(道具のダーク表示)で、一人が一人で選ぶ。掲示じたくで製品自身のライト/ダーク切替が押され、紙のまわりが 0.5 秒で明るくなる。後半は明るいまま、チーム → 組織 → 選ぶ瞬間の連打へ。
4. 選ぶ瞬間を同じ点・同じ大きさで 5 回連打したあと、最後の ○✓ の円が Compass の結果の「現在地」の点に切り替わり、引くと現在地から三つの橋へ分かれる実物の図になる(選んだ結果、選択肢が広がる)。そこから BRIDGE の二本の線の交点へ切り、引くとマーク、BRIDGE、EXPAND CHOICES.。
5. 砂色が現れるのは選んだ瞬間だけ(第22条「砂は選択の瞬間にだけ使う」をそのまま映像の規則にした)。映像のコピーは EXPAND CHOICES. だけで、画面の日本語はすべて製品の画面そのもの。

## 使った実物のページと状態(すべて保存データなしの新しい状態から、製品自身の操作で)

- `/compass/`(ダーク)職種「理学療法士(PT)」、1問目「周囲を巻き込んで解決する」を選んだ後の 2問目。選ぶのは「人に教えること」。問いの自動送り(選んで 0.26 秒後に次へ)は時間を止めて保持した
- `/tanaoroshi/`(ダーク)職種「リハビリ職」、9問目(後輩指導・教育)まで空欄で進めた状態の「やったこと」。入力は data.js の同じ問いの看護師向けヒントから「例えば、」を外した文(film/passage/capture.mjs と同じ入力例。作文なし)
- `/iikae/`(ダーク/ライト)一覧を「多職種連携」で絞る。星は実物のポインタのクリック。星の直後の通知は時間を止めて画面に出さない
- `/keiji/`(ダーク)種類「臨時休診」→ 入力は各欄の placeholder の「例:」の後ろ(製品の入力例)と固定の日付 2026-10-16 → 貼る(A4掲示)のできあがり → 右上の切替でライト
- `/clinic-flow-3d/`(ライト。ダーク表示はない)開始の扉「整形外科を引き継ぐ」→「1日」スキップで日を進め、経営の相談が開いたところで 2 つ目の選択肢を選ぶ。相談の中身はその回の乱数で変わる(「退院後の受け入れ相談を増やせそう/紹介を増やす動き方」「新患の入口をどこに置くか」を確認)
- `/compass/`(ライト)全問を上の選び方で答え、自由記述は「あとで」→ 結果「あなたの経験を、別の言葉にすると/人をつなぎ、育てる力」と地図。入場のアニメーションが終わるまで 13 秒待ってから撮る
- 署名だけ BRIDGE の面(`card/index.html`)

加工について: 撮ったあとに色・文字を変えたものはない。やったのは、拡大・切り抜き・カメラの移動と、時間の操作(製品の自動送りや通知を止めて保持する、入力の速さを上げる、遷移の途中から見せる)だけ。180° シャッターのぶれは副コマの平均で、速い寄り・引きのコマにだけ入る。

## 正直に弱いところ

1. **「すげー」の芯が演出の精度に寄っている。** 寄り→引きの文法そのものは、良い製品映像ではよく見る手つき。立ち止まらせるのは冒頭の「○ 人に」と砂色の円、巨大な文字と星の連打だが、中盤(掲示じたく・クリニックタウン3D)は「きれいに撮った画面」に戻る。P1 の視点で揃うマークのような、身体で驚く一回の仕掛けはこの案にはない。
2. **クリニックタウン3D だけ見た目の系が違う**(ゲームの青と灰の配色・情報量が多い)。組織の段として意味はあるが、画としてはいちばん弱い。相談の中身が回ごとに変わるので、撮り直すたびに画が変わる。
3. **明るくなる瞬間(S4)が静か。** 白い紙のまわりだけが 0.5 秒で明るくなる。身体の変化としては P1 の光に届かない。切替のボタンは画面の外で押している(押す手元は見せていない)。
4. **時間を操作している。** Compass の自動送り・言いかえ帳の通知は止めて保持、入力は実際の打鍵より速い(確定の単位で 1.7 秒)。連打は遷移の途中から見せている。実物の挙動ではあるが、実時間の記録ではない。
5. **文字が多い。** 日本語が読める人向け。360px 幅では、寄りの字(1920 幅で 80px 以上)は読めるが、引きの画面(掲示じたくの A4・Compass の結果の図)の小さな字は形としてしか届かない。
6. **マークの出し方は定石**(交点の寄りから引いて、文字を不透明度で出す)。映像全体の文法と韻は踏んでいるが、署名そのものに新しさはない。
7. **音がない。** 無音で成り立つよう作ったが、選ぶ瞬間ごとの小さな音があれば、連打と切り替えの気持ちよさは倍になるはず(未着手)。
8. 動きのぶれは 10 枚の副コマの平均なので、いちばん速い引きのコマで文字に段々の残像が出る(停止して見ると分かる程度)。
9. 縦(9:16)は未着手。
