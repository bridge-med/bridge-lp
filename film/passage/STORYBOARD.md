# PASSAGE(仮題)— 絵コンテとキュー表

15秒のブランド映像。空間に入っていき、プロダクトが次々に現れる。
「一本の線」(PR #131)とは別の映像として作る。あちらは平面の上で読み、理解する映像。

- 形式: 15.000 秒・1920×1080・60fps(縦 1080×1920 は同じ世界から撮り直す。未着手)
- 使い道: X・note の投稿。LP トップに置くかは未定(置くなら ia.md の改定が要る)
- 無音の自動再生で成り立つように作る。音は画が固まってから足す
- この文書は制作の記録。公開ページからはリンクしない
- 経緯: 2026-09-27 に骨格。2026-09-28 に社長が方向を採用し、P1 の直しを指示(カメラ・空間・写しの納まり・冒頭3秒・ロゴ形成・写しの差し替え・人の気配・コピー)。この版はその直しと、designer・批評役・QA の審査を受けた2回目の直し(§7 に記録)

## 1. 完成イメージ

白い建築を、カメラが一定の速さで、一本の直線の上を通り抜ける。

- 部屋は、個人 → チーム → 組織 と、幅・天井の高さ・壁の厚みが変わる
  - 個人: 幅 5.4・天井 2.7(低く狭い)
  - チーム: 幅 9.6・天井 4.2(低く横に広い。仕切りの壁で手前と奥の二つの間に分かれる)
  - 組織の広間: 幅 19.2・天井 12.0(縦に高い)
- 部屋の向きは広間の軸から +15° → +8° → 0° と少しずつ揃い、最後に建物の軸とカメラの見る向きが揃う
- 道具の画面(写し)は、通る口と同じ家族の開口の奥に、使っている途中の状態で納まっている
  - 前室では、通る口の隣の開口が道具になっている(選ばなかった道が道具)
- 最後の広間で一点 V に着くと、藍と砂がその一点から見たときだけロゴに揃う
  - 塗られているのは、V の 6m 先の格子(壁柱の正面)と、約 30m 先の奥の壁。近い層と遠い層が線に沿って交互に並ぶ
  - 格子の壁柱は、どれも V からの光線に沿って立つ。近づく途中は側面が重なって奥を隠し、V に着くと側面が消えて奥が開く
- 交点では砂が手前(V から 4.2m の薄い板)、藍が奥(約 30m の壁)。交わって見えても離れている
- V の 4.8m 先に高さ 1.1m の腰壁が横切り、BRIDGE と EXPAND CHOICES. はその無地の面に載る
- 動くのはカメラだけ。建築・写し・藍・砂は、最初から同じ場所にある

## 3. シーンごとの目的

- **冒頭(0〜3秒)**:
  - タイムラインで指を止める。文字を読ませることには頼らない
  - 360px 幅で読める三つ: 閉じた白い箱の台形(天井と床が見える)、右寄りの暗い塊、左寄りの奥へ抜ける明るい口
  - 暗い口と明るい口が同じ壁に並ぶ(分岐する道。第24条の補助モチーフ)
- **個人の部屋〜敷居1**:
  - 部屋は低く狭い。写しは左の壁に彫った斜めの区画に納まる。敷居1 は通る口だけ
  - 対象は患者に限らない(第4条)
- **チームの部屋**:
  - 天井は上がらず、横に広がる(梁が 3.6m ごと)。仕切りの壁で手前と奥の二つの間に分かれ、写しは一つの間に一枚
- **敷居2 → 広間**:
  - いちばん長く狭めてから、縦に高い広間へ出る(圧縮 → 開放)
  - 広間の手前は高い床(テラス)。腰壁の向こうに、広間の奥と格子がある
- **形成(10.8〜12.8秒)**:
  - 何になるかは最後の1秒前後まで分からず、視点が合った瞬間に BRIDGE と読める
  - 読める瞬間を決めるのは、視点が揃うこと。格子が開くのも、断片が揃うのも、同じ一点に近づいた結果
  - 動くのはカメラだけ。断片は画面の端から入ってこない(マークの重心はほぼ動かない)
- **署名**:
  - コピーでマークの意味を決めない(第24条の2)。映像のコピーは EXPAND CHOICES. だけ

## 4. 規則

### カメラ
- 焦点距離は 28mm 相当(横の画角 65.5°)で固定する。ズームとドリーズームは使わない
- ロール 0°・ピッチ 0°。鉛直線を常に鉛直に保つ(建築写真の規律)
- レンズシフトは全編 −0.06H で一定(地平線は y = 0.44H)。途中で変えない(疑似的なティルトにしない)
- 目の高さは 1.4m
- 経路は一本の直線。最後の視点 V の視線(広間の軸)に対して 20°、右後ろから左前へ
- 速さは 3.6 m/s で一定。止まるのは最後の一度だけで、止まる途中で 3.6 m/s を超えない
- ヨーは、V からマーク中心を通る光線の上の一点への方位。一点までの距離は、塗った断片の奥行きの調和平均(10.86m。マーク全体の重心が最後の 1.5 秒でほとんど動かない)。直線とその外の一点の組み合わせなので、向きは一方向にだけ回る(反転しない)
- 写しの前で減速・回頭しない。手持ち風の揺れ・オーバーシュートは使わない
- 最後の保持は完全に静止させる

### 空間
- 寸法は 0.6 の倍数。開口の上端 2.4m は全室共通(人の寸法の基準線)
- 天井はすべて閉じる。背景のクリア色が写る画素は 0(検査)
- 部屋の比例を変える(幅÷高さ 2.00・2.29・1.60)。同じ比例の箱を拡大しない
- 開口の大きさ・見込み・間隔は揃えない
- 敷居1: 口 1.2×2.4・見込み 1.2(通る口だけ)。敷居2: 口 1.8×2.4・見込み 2.4(いちばん長く縮める)
- チームの仕切りの壁: 厚み 0.9・天井まで。左の壁から x=0 まで。手前の面に言いかえ帳の開口
- 広間
  - 柱 1.2 角を 7.2m の格子に(x = −6.6 / 0.6 / 7.8)。柱の線上に梁 0.6×1.2。下の階は中央の 14.4m を柱なしにする
  - (0.6, −12.6) の柱は V の右 1.45m に立ち、V の画角の外。近づく途中では、格子の正面に塗った断片をこの柱が隠す
  - 腰壁: V の 4.8m 先を横切る、高さ 1.1m(テラスの床から)・厚み 0.3。V から見た上端は y≈0.53H で、マークの下端と BRIDGE の上端の間を通る
  - 腰壁から向こうは床が 1.2m 下がる(下の階)。下の階の床・柱の根元・奥の壁の足元は、どの視点からも腰壁に隠れる。左右の壁は、下の階の部分を目地と巾木なしにする(テラスの床から測った巾木が宙に浮かないように)
  - 格子: V の 6.0m 先に、見付け 0.3・奥行き 2.4 の壁柱を、約 0.75m ごと(間隔は決まった値で不揃い)に広間の幅いっぱい並べる。どの壁柱も V からの光線に沿わせる。上端はテラスの床から 4.2m(チームの部屋の天井と同じ高さ)
  - 奥の壁ぎわの一間(z = −34.2 の列)には柱を置かない(V から見て、柱の縁がマークの端に接するため)
  - 奥の壁: 目地なし(V から見て、格子の正面と同じ白に溶ける)
  - のこぎり状の壁(クリニックタウン3D): 左の壁から 35° 張り出す。先端は腰壁の手前で止まる

### 目地
- 色は面の段を一つ下げる(--card・--bg の面は --bg-2、--bg-2 の面は --bg-3、--bg-3 の面には引かない)。--line(半透明)は使わない
- 床: 0.6×1.2 の破れ目地。長い辺を部屋の軸に沿わせる
- 壁: 縦目地 1.2、横目地 2.4 ごと。足元に 0.03m の巾木の帯(--bg-3)
- 天井: 線なし(梁の形で見せる)
- 柱と腰壁: 目地を引かない。2.4m の基準線と巾木の帯だけ(壁と区別する)。基準線と巾木は、その面が立つ床から測る(下の階は −1.2m)
- 格子の壁柱と奥の壁: 線なし(V から見て、格子が奥の壁と同じ白に消えるように)
- 太さは実寸 12mm(画面で 1〜2px)。間隔が画面で 8px 未満になる所では消す(遠くの床に干渉縞を出さない)

### 写し(UI)の扱い(第22条の写しの但し書き)
- 実物のページから `capture.mjs` で撮る
  - 保存データなしから、製品自身の操作と入力例だけで「使っている途中」の状態にする
  - 撮る範囲(clip)は、映像の開口の比例に合わせて撮るときに選ぶ。サイトのナビ・ロゴは枠の外
  - 可逆の WebP で保存する(画素を変えない)
- 加工しない
  - 照明を当てない(`MeshBasicMaterial`・トーンマッピングなし)。縦横比そのまま
  - 色補正・ぼかし・書き換え・合成をしない
- 納め方
  - 開口の奥(壁の厚みの奥)に納める。面一にも額縁にもしない。見込みの面は向きの段で見せる
  - 通る口と同じ家族の開口に入れる。バッフル(独立した壁)は使わない
  - 真正面(0°)から見る瞬間をつくらない
  - 写しは裏の面から 20mm 浮かせる(奥行きの取り合いで縞が出ないように。描画の深度は 24bit)
  - 名前の札は置かない(designer の案。`?labels=1` で「まぐさに刻む」代案を確認できる。判断待ち §8)

- 除外の基準

### 同時に見える写し
- 一つの間に写しは一枚。次の写しは、敷居や仕切りを過ぎるまで見えない
- designer の基準「2枚目は画面の 3% 以下・合計 0.3 秒以内」を満たす(実測 0 秒)

### 色(第22条)
- 使うのはトークンの値だけ(`passage.js` の `TOK`。`render.mjs` が起動時に bridge.css の値と照合し、違えば止まる)
- 面は、世界に固定した光の向き(左手前)で平塗りする
  - 上向きの面: --bg。光に向く鉛直面: --card。光に背を向ける鉛直面: --bg-2。下向きの面: --bg-3
  - 床と天井の版: --bg-2
- 陰影・投影の影・AO・霧・グラデーション・グロー・ブルーム・粒子・グレイン・ビネットは使わない
- 藍(--navy)はロゴの断片だけ。砂(--dawn)はロゴの砂の線だけ。写しの中の藍・砂は数えない
- 明暗の混在: 白い建築の中に、ダーク表示の Compass の写しを1枚だけ置く(designer の判定は「可」)

### 書体(第23条)
- 署名
  - BRIDGE: Inter 500・字間 0.34em・--ink
  - EXPAND CHOICES.: Inter 500・字間 0.22em・--ink-3・大きさは BRIDGE の 8.5/15
  - マークの下に積む(映像だけの組み。判断待ち §8)。マークと文字の間は字高の 0.5 倍以上
- 900 は使わない。和文の一文は入れない(明朝の読み込みも外した)

### 動き
- 動くのはカメラだけ
- 動きのぼけはシャッター 180°。サブフレームを線形光で平均する(`engine.js`)
- 点滅: どの1秒でも大面積の明暗の切り替えを3回以下にする(WCAG 2.3.1)

### 藍と砂の塗り(Varini の方式)
- 最終の視点 V から見える面にだけ、正式の線を塗る(V からの距離の地図で判定。地図は一枚)
- 塗りを受ける面は二つの層に分かれ、線に沿って交互に並ぶ
  - 近い層: V の 6.0m 先の格子の壁柱の正面(壁柱は下の階の床 −1.2m から、テラスの床から 4.2m の高さまで。上端より上に広間の高さが見える)
  - 遠い層: 約 30m 先の奥の壁
  - 断片の奥行き(V から、実測): 藍 30・6・30・6・30・6m の 6 片(近い層に 9/33 点)、砂 6・30・4.2(板)・30・6・30m
- 交点の砂の板
  - 交点の前後 ±70px の砂だけは、V から見た輪郭が線そのもの(両端は正式の線と同じ丸い端)になる薄い板。V から 4.2m、光線に沿って 0.03m
  - 板は --dawn の平塗りの材料で、距離の地図には入れない
  - 奥の砂は交点の前後 62px で止め、丸い端で閉じる。V からは板がこの端を隠すので、ロゴの形は変わらない
  - 交点で藍は奥の面(約 30m)に乗る。砂と藍は別の物に塗られ、交差するが接続しない
- 隠し方
  - 格子は、V から外れた位置では側面が重なって閉じ、奥の層の断片を隠す。視線が揃うにつれて開く(拭き取りではなく、揃うことで見える)
  - 近い層の断片は、V の右の柱 (0.6, −12.6) が 10 秒台まで隠す
  - 格子の一本は、前室から一直線に見通せる位置を避けて置く(置くと 0 秒から奥に藍の点が見える)
  - 広間の入口の口は 1.4m。右の袖で、チームの部屋から格子の正面の塗りを一直線に見通す線を切る(1.8m では 6.75〜7.5 秒に砂の小片が見えた)
- 継ぎ目に塗り残しを出さないよう、距離の比較は隣の 3×3 の最大をとる
- 建築にアーチや円弧の部材を置かない。弧の両足を同じ奥行きの2本の柱に乗せない(橋の図像にしない)

## 5. 実装方式

**既存の HTML/Canvas の書き出し基盤を広げ、three.js で作る。Remotion は入れない。**

| 判断軸 | HTML + three.js(採用) | Remotion |
|---|---|---|
| 実装速度 | 描画器・書き出し・写しの撮影がすでに動いている | React・バンドラ・独自の Chrome の取得から始まる |

| 派生への展開 | 同じ世界から撮り直せる。縦版は視点とマークの置き場を縦用に持てばよい | 構成の管理は得意。ただし今回の派生は同じ3Dの撮り直し |

designer が答えを出した事項(判断待ちから外す):
- 最後の画に格子を残してよい。痕跡(目地の途切れ・床の帯)は消す → 奥の壁の目地を外し、床の帯を腰壁で隠した
- 10.8〜11.8 秒の砂は、形成の区間の砂(第22条の選択の瞬間)として受け入れる。条件は、10.0 秒より前は 480px の画で 7px 以下であること(柱の縁に覗く小片だけで、線の形に読めない)。実測(0.05 秒ごと)は 9.2〜9.75 秒に 3〜7px、10.0〜10.45 秒に 3〜16px

designer の案からの変更(2回目):
- ロックアップの後ろ: 「V から 7〜18m の床だけ」ではなく、腰壁の無地の面。藍の近い層を 4〜7m に置くと、床から立つ物は必ずロックアップの箱に入る。腰壁で近い層の根元を隠し、文字の後ろを一枚の面にした
- 近い層の面: 45° 以上傾けた面ではなく、光線に直交する壁柱の正面。傾けた面の代わりに、壁柱の側面が V から外れた視点で断片を隠す。藍だけの残差の目標は満たす
- 近い層に乗る藍: 9/33 点(27%)。目標の 40% に届かない。前室から一直線に見通せる位置に壁柱を置かないため
