# P2 別案 日の庭(SUN COURT)の試作

夜の比較で、P2「光が主役」の構想を選ぶ役が選んだ案の一式です。**wip・held。公開ページからは読み込まれません。**

広間を陰にしておき、羽板が V で真横を向いた瞬間に、奥の日の当たる庭が開きます。マークは塗りのまま(藍と砂はトークンの色)です。設計・測った数字・既知の逸脱は `SPEC.md` にあります。

- `make_scene.py`: `../export.mjs` の書き出しから、日の庭の場面(羽板を 12 m の陰の幕に、庭の屋根を開ける等)を作る
- `build_court.py` と `arch.osl`: 描画器(層ごとの塗料、塗りの面の鏡面反射を切る)
- `audit.py`・`measure.py`・`solve.py`: 光線での幾何の確認、写真としての計測、太陽と空の強さの分解
- `court-clip.json`・`court-hold.json`: 10.8〜12.8 秒の短い動画と、最後の画の設定

**そのままでは動きません。** パスは夜の作業環境(`/tmp/claude-0/...`)を指しています。
