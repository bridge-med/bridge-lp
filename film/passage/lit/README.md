# PASSAGE 光ありの描画器(試作)

2026-09-28 の夜の比較で使った、Blender 4.2 Cycles(CPU)で PASSAGE を物理的な光で描く一式です。**wip・held。公開ページからは読み込まれません。**

- `../passage.js` の `exportScene`・`exportDepth`・`exportMask`・`exportLockup` で場面を書き出し(`export.mjs`)、`build.py` が Blender で組み立てて描きます
- `arch.osl`: 壁と床の材質、V からの Varini の塗り(距離の地図と覆いの画で判定)
- `mkcfg.py`: 光の規則(`BIBLE.md`)に沿った設定を V の位置から作る
- `clip.py`: コマを並べ、最後の画を保持し、署名を重ねて mp4 にする。`endcard.py` は最後の画だけ
- `p2clip.py`: P2「光が主役」の試作。屋根と庇に穴を開け、V から見たときだけ日光がマークの形に落ちるようにする
- `BIBLE.md`: 光と素材の規則(designer の起草。未決の項目は §17)

実測: 480×270 で 1 コマ 8〜12 秒、640×360 で約 22 秒、960×540 で 70〜90 秒(4 コア)。1920×1080 で 15 秒を描くと 30 時間を超えます。

既知の不具合: 6.0〜7.6 秒で敷居の天井が黒く抜ける。腰壁の上に羽板の下端が灰色の四角として見える。

**そのままでは動きません。** Blender と ffmpeg の場所、書き出し先は夜の作業環境(`/tmp/claude-0/...`)を指しています。
