# PASSAGE 光と素材の手引き(P1 光あり・P2 光が主役)— designer 2026-09-28 v0
対象は Blender 4.2 Cycles(CPU)。経路・部屋の寸法・写しの位置・塗りの幾何は STORYBOARD のまま。変えるのは光・素材と、光を入れる開口だけ。
座標は passage.js(x=右・y=上・z=手前、広間の軸 −z)。Blender へは (x, y, z)ᵦ = (x, −z, y)。「未計測」と書いた値は起点で、§12 の較正で決める。

## 1. 原則
- 光は太陽1つと空だけ。照明器具・隠した補助光を置かない(病院・オフィスの天井照明の連想を断つ)。部屋ごとの差は開口の形だけでつくる。
- 光源を見せない。空・太陽・開口の向こうが写る画素は 0(旧「クリア色 0px」の置き換え)。光は、落ちた面でだけ見せる。
- 光は無彩色。色は面が持つ(token から出した基本色)。影は生成り→砂の軸で暗くなり、青(藍)へ寄せない。
- 動くのはカメラだけ。太陽を動かさない。変わるのは視点で、光の見え方も視点で変わる。
- 光の形は四角・帯・正式の曲線だけ。十字(医療・教会)と円弧の窓(橋・アーチ)の光をつくらない(第21条・第24条)。開口の寸法は 0.6 の倍数。天窓どうしを直交させない。

## 2. 太陽と空
- 時刻: 秋分の正午の東京に近い高度 52°。夜明け(v1.1 で廃した世界観)にも夕暮れの郷愁にも寄せない、いちばん中立な光。
- 方位: V の後ろ、広間の軸から左へ 20°。太陽への向き s = (−0.2106, 0.7880, 0.5785)(Blender では (−0.2106, −0.5785, 0.7880)、Sun の Rotation XYZ = (38°, 0°, −20°))。光は右前下へ流れる。理由: 格子の正面と奥の壁(どちらも +z 向き)に同じ直射が当たり、右から近づくカメラが見る格子の右向きの側面は陰になる(§8)。
- Sun: Angle 0.53°(実際の太陽。大きくするとスタジオの柔らかい影になる)、Color (1,1,1)、Strength 3.0(未計測)。
- 空: World は Constant、Color (1,1,1)、Strength 1.0(未計測)。Nishita は使わない(影が青に寄り、藍と IT 感に近づく)。空は画に写らず、開口から入る柔らかい光としてだけ働く。
- 暖色の光は使わない(個人の部屋にも)。砂=温度を部屋全体に撒くことになる(第22条)。温かさは漆喰の色相と照り返しから出る。

## 3. 露出と色の管理(写しを守るための固定値)
- Display sRGB / View **Standard** / Look None / Exposure **0** / Gamma 1 / Curves OFF / Dither **0**。出力は PNG 8bit RGB。
- AgX・Filmic を使わない(token の藍・砂と写しの画素を曲げる)。Standard は 1.0 で切れるので、ハイライトに合わせる(建築写真と同じ規律)。露出は 0 から動かさず、明るさは太陽と空の強さだけで合わせる(写しの Emission 1.0 が露出 0 を前提にする)。

| B 明るい陰 | 空と照り返しを受ける面。ロックアップの腰壁 | 88〜95 | --bg-3 #EAE2D3〜--bg-2 #F4EFE6 |

- 建築の画素は 253 を超えない(どのチャンネルも)。超えたら光の強さではなく、その面の開口を直す。

- 冒頭〜チームは「奥ほど明るい」(進む理由)。敷居2 が全編の最暗。広間の奥の壁が全編の最明。

## 6. 写し(第22条 写しの但し書き)
- Shader は Emission だけ(Strength 1.0、Image Texture: Color Space sRGB・Alpha None・Interpolation Linear)。BSDF を混ぜない。§3 の固定値と組で、画素は元の値のまま出る。
- Object > Visibility > Ray Visibility は Camera だけ ON。写しは部屋を照らさず、床や壁に映らない(写しの色を枠の外へ持ち出さない)。
- ノイズ除去から外す: Denoising Data を出し、合成で写しの ID Mask(写しの Pass Index = 1、Anti-Aliasing ON)の範囲だけ Noisy Image を使う。
- 写しは光を受けないので、光のほうを写しに合わせる。明るい写し(棚卸し・言いかえ帳・掲示じたく・クリニックタウン3D)は、写しの地と隣の見込みの差が +3 L* 以内に収まる光の中に置く(暗い壁の中で明るい写し=壁のディスプレイ。P1 で社長が退けた見え方)。影の縁・日なたの縁を写しにかけない。写しは一つの光の中に丸ごと入れる。
- 恒等の検査: 正投影・1 texel = 1px・Pixel Filter 0.01px の試験画で、元画像との差が 8bit で 1 以下。本編の拡大縮小・フィルタ・動きのぼけは「縮小・移動」の範囲。

## 7. 藍と砂の塗り
- 基本色 = token の線形値 ÷ E。E = その面の漆喰の出力(線形)÷ 漆喰の基本色(線形)。V の画で、塗りの脇の白から測る。
- 起点(奥の壁を --bg に較正したとき E≈1.18): 藍 #142039、砂 #9D855C。一色に一つの塗料が原則。層で E が違えば光を直し、直せないときだけ層ごとに調合する。
- 交点の砂の板は腰壁と同じ陰にある別の物(§8)。板だけ別に調合(起点 #E1BF85。E が日なたの 45% のとき)。
- 合格: V の画で、各層と板の線の芯(縁の 2px を除く)の中央値が token から ΔE00 ≤ 2。線に沿った明るさのむらが ±5% 以内。超えたら格子の正面を V ではなく広間の軸に直交させる(側面は光線に沿わせたまま。正面の直射が奥の壁と等しくなる)。

## 8. 広間と V(形成を光で支える)
開口は二つ。どちらも経路のどこからも見えない(画の上端は仰角 17.7°)。
- (a) 奥の光井戸: z = V−21 から奥の壁(V−30)までの天井を 24m に上げ、太陽側の面の 12〜24m を開ける。奥の壁は足元からテラスの床上約 11.7m まで直射で洗われる。影の縁は V の画の上に出る。高窓は手前の天井の縁に隠れる。
- (b) V の上のスリット: 天井 12m、z = V−0.3〜V+2.4、格子の全幅を覆う幅で、左へ約 2.7m ずらす。格子の正面を高さ 0.6〜4.2m まで直射で照らす。腰壁・テラスの床・交点の板には直射が落ちない(日は腰壁の向こうの下の階に落ち、腰壁に隠れる)。
- 近づく途中: 格子の右向きの側面は陰(帯 C〜D)。陰の縞が格子を閉じ、その上に日なたの奥の壁が高く見える。
- V: 側面が消えると陰の縞も消え、画の上半分が一枚の日なたになる。揃う一点で影が見えなくなる——形の揃いと光の揃いを同じ一点に重ねる。テラスは奥の壁の照り返しで満たされる(帯 B)。
- 測る目標: 11.3→12.8 秒で、マークの外接箱の中の塗っていない画素の平均 L* が +10 以上上がる。1コマの変化は 1 L* 以下(WCAG 2.3.1)。

## 10. 終わりの画(12.8〜15.0)
- 構図: 上半分は日なたの格子と奥の壁(帯 A)にマーク。下は陰の腰壁(帯 B、L* 88〜93、ロックアップの箱の中で ±1.5 L*、影の縁を入れない)にロックアップ。マークは光の中、文字は手前の陰。
- 文字は描画のあと、表示の sRGB で重ねる 2D の文字。--ink・--ink-3 の値そのまま。3D の面に塗らない(光で色が変わる、ノイズが乗る、不透明度のフェードが物理に合わない)。コントラストは --ink 13:1 以上、--ink-3 は L* 90 で 4.6:1。
- 12.8〜15.0 は 1 枚を高いサンプル数で描いて保持する(静止は本当に静止。ノイズを揺らさない)。

## 11. 許すもの・禁じるもの
| 許す(物理の結果) | 禁じる |
|---|---|
| 太陽と空の光、0.53° の柔らかい影の縁、多重の照り返し(白の系の中の色のにじみ)、照り返しの結果としての隅の暗さ、床の鈍い映り込み(Roughness ≥ 0.4)、漆喰の細かな凹凸、形でつくる影の目地、動きのぼけ(180°) | ブルーム・グレア・レンズフレア・霧・光の筋(ゴッドレイ)・被写界深度・グレイン・ビネット・色収差・粒子・ネオン。AO パスの掛け算・Fast GI の近似。HDRI の空。隠した補助光。空や太陽が写ること |
- 霧と光の筋を禁じる理由: CG と AI の定番で、30m の奥の層だけが霞み、藍と砂が層ごとに別の色に割れる。被写界深度: 6m と 30m の層が同時に鋭くないと V で形が揃わない(建築写真と同じ深い焦点)。グレインとビネット: 写しの画素を変える加工で、「フィルムらしさ」の上塗り。

## 12. 較正と合格の検査(この順で。露出は触らない)
1. §6 の恒等の検査に通す。
2. V の画で、奥の壁の塗っていない 40×40px の中央値が #FBFAF7 ±2 になるよう Sun Strength を決める。
3. 腰壁の面が L* 88〜93 になるよう World Strength を決める。以後、太陽と空の強さは全編で一つ。
4. §7 の塗りの ΔE00、§8 の +10 L*、§4 の 253 と最暗 L* 55 と陰の色度、§6 の +3 L* を測る。
5. 外れたら開口の位置と大きさで直す。部屋ごとに光を強めない。

## 13. 描画の予算(4コア・CPU。どの描画も flock /tmp/claude-0/render.lock を通す)
- 今夜の比較: 960×540・30fps(450コマ)。Adaptive(Threshold 0.03・Max 64spp)、OIDN(Albedo+Normal・Prefilter Accurate)、Light Tree ON、Bounces Total 8 / Diffuse 4 / Glossy 2 / Transmission 0 / Volume 0、Caustics OFF、Clamp Indirect 10、Motion Blur ON(Shutter 0.5)、Persistent Data ON。
- 要所の止め絵: 1920×1080・256spp、t = 0.0 / 2.7 / 4.7 / 6.1 / 8.6 / 11.3 / 12.8 / 14.0(現行の after3 と並べる時刻)。
- 12.8〜15.0 の保持画は 1920×1080・1024spp を1枚。公平のため、エンコードは full-p1.mp4 と同じ設定にする。

## 14. P2(光が主役)に足す規則
- 世界は P1 と同じ(太陽・空・露出・素材・写し・禁止)。太陽を動かさない(早回しの影はストック映像の定番)。
- 光で形をつくるなら Varini の方式を光で行う。天井や格子に切った型を通った日が、近い層と遠い層に断片として落ち、V からだけ揃う。
- 縁の鋭さは太陽の視直径で決まる。半影の幅 = 0.0093 × D(型から受ける面までの m)。V から L m の面では 1920px で 15.5·D/L px。縁を 3px 以内にするには D/L ≤ 0.19(30m の奥の壁なら、型は壁から 5.7m 以内)。
- 光の線は周りが帯 C〜D(L* 75 以下)でないと読めない(ΔL* 20 以上)。P2 の広間は P1 より暗くてよい。ただし最暗 L* 55 と陰の色度は守り、光を筋や霧で見せない。

## 15. STORYBOARD §4 のうち、この手引きが置き換えるもの
| §4 の規則 | 置き換え | 理由 |
|---|---|---|
| 色: 面を固定の光の向きで平塗り(上 --bg・光に向く --card・背 --bg-2・下 --bg-3・床と天井の版 --bg-2) | 基本色は §5、明るさは物理の光の結果(§4) | 平塗りは模型・グレーボックスに見える。社長の「ちゃっちい」の第一原因 |
| 陰影・投影の影・AO・霧・グラデーション・グロー・ブルーム・粒子・グレイン・ビネットは使わない | 陰影・影・照り返しを許す(§11)。霧・グロー・ブルーム・粒子・グレイン・ビネットは引き続き禁止 | 足した飾りではなく光の結果。飾りの禁止は残す |
| 目地(壁の縦 1.2・横 2.4、--bg-3 の巾木の帯、面の段を下げた色の線) | 壁は目地なしの漆喰。床は溝。巾木は影の目地(§5) | 色の線の目地は、光のない画で面を読ませる代用だった。光があれば形が読ませる。壁のタイル目地は病院の廊下に寄る |
| 写し: MeshBasicMaterial・トーンマッピングなし | §6(Emission 1.0・Standard・露出 0・照らさず映らない・ノイズ除去から除外) | 同じ規則(加工しない)を Cycles で守る方法 |
| 天井はすべて閉じる・クリア色 0px | 光の開口を足す。空・太陽が写る画素 0 | 光を入れる。見せないことで模型の穴にしない |
- 残すもの: 藍と砂はロゴの塗りだけ、Compass の明暗の混在、書体、動き(180°)、避ける表現、空間の寸法と経路、写しの一覧と状態。

## 16. 憲法との照合
- 第21条: 白と余白が基調のまま(帯 A〜B が各画の過半。敷居2 を除く)。医療感は、照明器具なし・艶なしの漆喰と石・青くない影・十字の光の禁止で避ける。IT 感は、ガラスの壁・青い光・線の照明を置かないことで避ける。
- 第22条: 光は無彩色で、色の系統を増やさない。藍と砂はロゴの断片だけ。写しは §6 で無加工・枠の外へ色を出さない・一つの間に一枚。
- 第24条: 形成は変えない。光は「揃う一点で影が消える」として交差を支える。弧の光・橋の図像をつくらない。
- 第13条: 光は計算の結果で、写しは実物のまま。塗料の調合は架空の建物の設計であり、画面の捏造ではない。

## 17. 保留(社長の判断)
1. 陰の明度。光を入れると陰の面は --bg-3 より暗い値(L* 55〜88)をとる。色相は生成りのまま(§4 の色度)。これを第22条の「白・生成り系」の内と見るか。design-system の「グラデーションを足さない」に当たらないと見るか。designer の見立ては「内」(色を足していない。光が白を白に見せている)。朝の P1 を見て決める。
2. P2 で光だけで描いた線は白く、藍と砂を持たない。これを正式ロゴ(藍と砂の二本の線、第24条)の表現と認めるか。認めないなら、P2 の形成は P1 と同じ塗りで行い、光は「開く」役にとどめる。
