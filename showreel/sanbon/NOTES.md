# 一本から三本に — 制作ノート(philosophy「選択肢を増やすということ」の版)

philosophy(`philosophy/index.html`)の #expand の分岐の図(`.branch-fig` の SVG)を、同じ語・同じ位置の 14 秒の映像に置き換えたもの(2026-10-10・無音・60fps・H.264)。社長の「3か所に映像を」(2026-10-09)の 3 本目。言葉は editor が描画の前に確定した(下の絵コンテ)。「いま」の点から一本の道が伸び、目標が「歩行の自立」から「孫の運動会に行く」へ変わり、分かれ目の点(砂)が灯って、三本の道が同時に同じ時間で伸びる。最後の 1 コマは図と同じ姿で静止する。ロゴの finale は付けない(同じページの re + habilis が持つ)。

- 版: テーマ × 画角の 4 本(`{light,dark}-{wide,tall}.mp4`)とポスター 4 枚(`.webp`・14.0 秒の完成形)。wide=1760×600(図の viewBox 880×300 の 2 倍。最後の 1 コマは図と同じ語・同じ位置)、tall=1080×1350(≤760px。道を上から下へ流す縦の組み。語は同じ、字は大きい)
- 色は図の CSS と同じ役割: 点と図のラベル(b)=`--ink`、一本の道と小さいラベル=`--ink-3`、三本の道=`--navy`(ダークは `--blue`)、分かれ目の点だけ `--dawn`(B-14 の修正と同じ。中央の道を砂にしない)
- 書体: 図のラベル=Noto Sans JP 600(字間 0.08em)、目標の二語=明朝(Shippori Mincho B1 600)。英字は出ない
- 描画は `reel.html`(時刻 t だけで 1 枚が決まる canvas)。`?theme=light|dark&layout=wide|tall`

## 書き出し

```sh
D=showreel/sanbon
for th in light dark; do for ly in wide tall; do
  node showreel/render.mjs --page $D/reel.html --query "theme=$th&layout=$ly" --samples 4 --noaudio 1 --crf 18 --out $D/$th-$ly.mp4
  node showreel/render.mjs --page $D/reel.html --query "theme=$th&layout=$ly" --stills 14.0 --samples 1 --outdir /tmp/sanbon-$th-$ly
  ffmpeg -y -i /tmp/sanbon-$th-$ly/t14.000.png -c:v libwebp -quality 88 -compression_level 6 $D/$th-$ly.webp
done; done
```

## 指摘と代案（たたき台に対して）

1. **第19条2号＋第20条＋209行との整合** — たたき台「三本に分かれ、挑戦する・選び直す・続けるが順に立つ」
   - 上から順に等間隔で立てると、拍が三連になり、しかも「挑戦する」が一番手に見える。本文 209行は「挑戦する人だけが正しいわけではありません。いまの場所で続けることも、立派な選択です」と言っている。画が順位を付けると本文を裏切る
   - 代案: 「分かれ目の点から三本が同時に、同じ時間で伸び、道の先に三語が同時に出る」（表の 8.40–10.40）。同じ速度で引くと中央の道（短い）が先に届くので、速度ではなく時間を揃える
2. **第13条・意味の捏造の防止** — たたき台「本文の三つの手段を三本の道に添えるか」
   - 出さない（上の表）
3. **最後の1コマとの整合** — たたき台は目標の語の退場を決めていない
   - 代案: 「孫の運動会に行く」は分かれ目の点が灯り「可能性に気づく」が出たあと（8.00–8.40）、三本が伸び始める前に退場。三本が目標の語を貫いて通る画を作らない。最後の1コマに図にない語を残さない

## 確認が要る点

1. **砂の位置（designer・PM）** — 現行の図では、砂は分かれ目の点にない。203行の `fill="var(--dawn)"` は 60行の CSS `.branch-fig .dot{fill:var(--ink)}` に負けて炭で描かれ、砂は中央の道（198行 `.opt.d`「選び直す」）に乗っている。依頼の「砂は分かれ目の点だけ」と「最後の1コマは現行の図とまったく同じ」は、色についてはぶつかる。editor の推奨は「語と位置は現行のまま、砂は点へ移し、中央の道は他の二本と同じ藍にする」。一本だけ砂の道は「推奨の道」に読め、209行と `.branch-cap` の「どの道を選んでもいい」に反する。この場合、HTML に残る JS なしの代替（もしあれば）も同じ色にそろえる
2. **画角（designer）** — 現行の図は 880:300。16:9 にすると上下に余白ができ、ページの組みが変わる。最後の1コマを現行と同じ姿にするなら 880:300 の比（例 1760×600）を推す
3. **スマホでの字の大きさ（designer）** — 現行の図は 375px 幅で 11〜12 のラベルが約 5px まで縮み、すでに読めない。焼き込みにすると拡大もできない。re + habilis のような縦長の版を作るなら位置が変わるので「最後の1コマは現行と同じ」を PC 版に限るか決めが要る
4. **例の扱い（社長）** — 「歩行の自立 → 孫の運動会に行く」は本文で「想像してみてください」と前置きした想像の例。映像では前置きが消える。人物を描かず二語だけなら事例の実話化には当たらないと判断したが、社長の一次体験に近い例があるなら、そちらへ差し替えるかどうか（第13条: 一次体験が存在する領域では架空のスケッチを優先しない）
5. **範囲外の気づき（参考）** — このページの「ではなく」は本文で 14 回ある（第19条1号の原則1回を大きく超える）。映像は 0 回で増やさないが、ページ全体の照合は別件として起こす価値がある
