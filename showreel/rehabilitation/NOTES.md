# re + habilis — 制作ノート

憲法第3条(リハビリテーションの定義)と第4条(対象)を、そこに書いてある言葉だけで動かす 16 秒のモーショングラフィックス(60fps・H.264・無音)。2026-10-04、社長の「もう一枠使う」指示で作り、2026-10-05 の社長指示「LPの中になんかうまいこと組み込めないかね」で**思想ページ(`philosophy/index.html`)の「リハビリテーションとは」の節(#rehabilitation)の末尾に置いた**。節の文章と同じ順序を映像で見せる。文章は置き換えない。トップには置かない(§1 Motion の常時ループは Journey だけ)。v3「一本の線」の扱いは別の話で、今回は触れていない。

- 版: テーマ × 画角の 4 本とポスター 4 枚(`{light,dark}-{wide,tall}.mp4` / `.webp`)。wide=1920×1080(16:9・PC)、tall=1080×1350(4:5・≤760px)。ページはテーマと画面幅で 1 本だけを、近づいてから読み込む。ポスターは 12.0 秒(六語が線の上に揃った画。designer 2026-10-05)
- 描画: `reel.html`(時刻 t だけで 1 枚が決まる canvas)。`?theme=light|dark&layout=wide|tall` で版を選ぶ。道具(easing・文字の組み・ロゴの経路・finale)は `../namae/v3-parts.js` を読む。正式ロゴの経路の写しを増やさない(design-system B-13)
- 書き出し(4 本とポスター):
  ```sh
  D=showreel/rehabilitation
  for th in light dark; do for ly in wide tall; do
    node showreel/render.mjs --page $D/reel.html --query "theme=$th&layout=$ly" --out $D/$th-$ly.mp4
    node showreel/render.mjs --page $D/reel.html --query "theme=$th&layout=$ly" --stills 12.0 --samples 64 --outdir /tmp/rh-$th-$ly
    ffmpeg -y -i /tmp/rh-$th-$ly/t12.000.png -c:v libwebp -quality 88 -compression_level 6 $D/$th-$ly.webp
  done; done
  ```
  止め絵だけなら `--stills 1.3,5.0 --outdir <dir>`。動く時刻の止め絵を mp4 と比べるときは `--samples 64` を付ける(`--stills` の既定はぼけなし)
- 要るもの: node 22、playwright(chromium)、ffmpeg(libx264・libwebp)、curl(Google Fonts を一度だけ取り、OS の一時領域に置く)。`playwright` がリポジトリの `node_modules` から見つからないときは `ln -s /opt/node22/lib/node_modules/playwright node_modules/playwright`
- 音: Web 用は無音で確定(ページでは muted で再生する。PM 2026-10-05)

- 砂が出るのはロゴの砂の線だけ。第4条の場面に分岐点を置かない(PM 2026-10-04: 砂は選択の瞬間に限る。「患者」が他へ分かれるという条文にない意味を画に作らない。同じ一本の線=「対象は違っても、考え方は同じ」)
- 文字はすべて憲法の語句のまま。語順を変えない。「〜ではなく」は画で演じ、文字には出さない(第19条1号。作中 1 回)
- 色はテーマのトークンの値。線とロゴの藍の線は役割 `--mark-line` の値(ライト `--navy`・ダーク `--ink`)、砂は `--dawn` のダーク値

- 仮題「re + habilis」は editor の案(第3条の語そのまま・句読点なし)。先の仮題「再び、ふさわしく」は憲法にない活用形のため使わない

## 2026-10-10 地を帯の色に、線の端を地へ溶かす

思想ページの窓を縁なしにした(社長「境界線が無い方が見やすい」・design-system v1.4)。#rehabilitation は帯の節(`.sec.tint`)なので、`?ground=tint` で地を `--bg-2`(ライト #F4EFE6・ダーク #161B2B)にして4版とポスターを書き出し直した。あわせて、場面 3 の「左の外から右の外へ」の一本の線が窓の端で切れないよう、線と文字を層に描き、端の 3%(32px)で地へ溶かしてから地に重ねる。書き出しは上の手順の `--query` に `ground=tint&` を足す。
