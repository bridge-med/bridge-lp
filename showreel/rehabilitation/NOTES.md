# re + habilis — 制作ノート

憲法第3条(リハビリテーションの定義)と第4条(対象)を、そこに書いてある言葉だけで動かす 16 秒のモーショングラフィックス(1920×1080・60fps・H.264・無音)。2026-10-04、社長の「もう一枠使う」指示で作った追加の一本。**wip・held。公開ページからは読み込まれない(NAV・サイトマップ・一覧に載せない)。** 用途(v3「一本の線」と並べる・差し替える・保管)は社長の判断待ち。

- 描画: `reel.html`(時刻 t だけで 1 枚が決まる canvas)。道具(easing・文字の組み・ロゴの経路・finale)は `../namae/v3-parts.js` を読む。正式ロゴの経路の写しを増やさない(design-system B-13)
- 書き出し: `node showreel/render.mjs --page showreel/rehabilitation/reel.html --out showreel/rehabilitation/showreel.mp4`(`--stills 1.3,5.0 --outdir <dir>` で止め絵だけ)。render.mjs は v3 と共用(2026-10-04 に `--page` を足した)
- 要るもの: node 22、playwright(chromium)、ffmpeg(libx264)、curl(Google Fonts を一度だけ取り、OS の一時領域に置く)。`playwright` がリポジトリの `node_modules` から見つからないときは `ln -s /opt/node22/lib/node_modules/playwright node_modules/playwright`
- 音: 未着手(P3 と同じ)。終わりは完全静止なので後から足せる
