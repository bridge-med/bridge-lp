# 医療管理実務ライブラリ(仮称) — medops/

医療機関で具体的な業務・案件が発生したときに「**何を・誰が・いつ・どの順番で処理するか**」を確認できる実務ライブラリ。
採用、入退職、施設基準、研修記録、レセプト返戻、医療機器管理などの、チェックリスト・台帳・進捗表・文例を提供する。

ブランド名は仮称。**`medops/data/site.mjs` の `SITE.name` 以外にハードコードしない。**

## manager-starter との棲み分け(2026-07-18 社長指示で改定)

- **医療管理職スターター(manager-starter/)** = 「管理職としてどう振る舞うか」(1on1・上司報告・チーム運営・最初の90日)
- **医療管理実務ライブラリ(本サイト)** = 「具体的な実務をどう処理するか」(案件処理のチェックリスト・台帳・文例)

迷ったらこの2問で判断する。管理職教育系のコンテンツは本サイトに置かない
(旧コンテンツの1on1シート・業務分担シート・新任事務長30日などはdraft化して保持。スターターへの移管は社長判断待ち)。
スターターへの案内は「初めての方へ」とフッターに限定し、テンプレート一覧に混在させない。

## 起動方法

静的サイトなのでビルド・サーバーは不要。ローカル確認は:

```
python3 -m http.server 8000   # リポジトリルートで実行
# → http://localhost:8000/medops/
```

## 構造

```
medops/
  data/            唯一の情報源(ES Modules。Node生成スクリプトとブラウザ両方が読む)
    site.mjs       ブランド名・価格・ナビ・計測イベント名・絞り込み軸(対象者/場面/頻度/形式)
    categories.mjs 実務カテゴリ9(採用・面接/入退職/安全研修/施設基準/システム/機器物品/地域連携/文書/特殊案件)
    templates.mjs  テンプレート(公開43=全て無料 + draft)。scenes/frequency/confirmationTargets等の実務メタつき
    articles.mjs   記事(公開13 + draft)
    product.mjs    代表商品「採用・入退職実務パック」(収録25点。status 1操作で公開/保留切替)
  assets/
    medops.css     デザインシステム(BRIDGEトークン。ライト/ダーク)
    medops.js      ランタイム(テーマ/絞り込み/検索/コピー/問い合わせダイアログ/計測スタブ)
  index.html ほか  すべて生成物。手で編集しない

scripts/medops/
  build.mjs        全HTMLを静的生成し、ルート sitemap.xml のマーカー区間を更新
  html.mjs         共通レイアウト・カード部品・JSON-LD
```

## コンテンツの追加・変更

1. `medops/data/*.mjs` を編集(テンプレ・記事の追加は1オブジェクト)
2. `node scripts/medops/build.mjs` で全ページ再生成+sitemap更新
3. `node scripts/check-site.mjs` で機械検査
4. `ship` スキルに従って出荷

- 価格変更: `site.mjs` の `pricing` だけ(パックは `recruitPack`)
- `status:'draft'` はページ生成・一覧表示なし(憲法第14条)。slug変更時は旧ディレクトリを手で削除
- **公開テンプレの品質条件**(PM 2026-07-18): 確認項目が実際に列挙された実用粒度のデータを持つこと。中身のない予告ページを作らない

## 設計判断のメモ

- **公開テンプレートはすべて無料**。収益化はパック(完全版一式+文例)で行う
- **代表商品は「採用・入退職実務パック」**(日常反復業務)。統合・閉院パックは特殊案件のためdraftで保持(中心商品にしない — 社長指示)
- **価格表示**: 初期販売価格12,800円を主表示し、通常価格19,800円は「初期販売期間の終了後に適用」と適用時期つきで明記(実績なき二重価格に見せない)。**初期販売期間の終了条件(期日/条件)は社長未決**
- 決済準備中の明示・CTA問い合わせ方式・JSON-LDにOfferなし・偽メトリクスなし(従来方針の継続)

## 販売開始までに必要な作業

1. パック実ファイル25点(Excel/Word)の作成
2. 初期販売期間の終了条件の決定(社長)
3. 決済(Stripe Payment Links が最小)+ **特定商取引法に基づく表記**(必須)
4. 法務3枚の専門家確認(manager-starterの3枚と同一水準の仮文面。確認は両サイト分を1回で)
