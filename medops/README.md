# 医療管理実務ライブラリ(仮称) — medops/

医療管理職(訪問診療クリニックの事務長・医療法人本部・新任管理職)向けの実務プラットフォーム。
無料記事・無料テンプレート → 有料テンプレート → 会員プラン、と段階的に発展させる前提のMVP。

ブランド名は仮称。**`medops/data/site.mjs` の `SITE.name` 以外にハードコードしない。**

## 起動方法

静的サイトなのでビルド・サーバーは不要。ローカル確認は:

```
python3 -m http.server 8000   # リポジトリルートで実行
# → http://localhost:8000/medops/
```

## 構造

```
medops/
  data/            唯一の情報源(ES Modules。Node生成スクリプトとブラウザ両方が読む)
    site.mjs       ブランド名・価格・プラン・ナビ・計測イベント名・絞り込み選択肢
    categories.mjs 実務テーマ(7カテゴリ)
    templates.mjs  テンプレート商品(公開9 + 下書き)
    articles.mjs   記事(公開5 + 下書き)
  assets/
    medops.css     サブサイト専用デザインシステム(BRIDGEトークン踏襲・ライト/ダーク)
    medops.js      ランタイム(テーマ/ドロワー/絞り込み/検索/コピー/購入モック/計測スタブ)
  index.html ほか  すべて生成物。手で編集しない

scripts/medops/
  build.mjs        全HTMLを静的生成し、ルート sitemap.xml のマーカー区間を更新
  html.mjs         共通レイアウト・カード部品・JSON-LD
```

## コンテンツの追加・変更

1. `medops/data/*.mjs` にオブジェクトを追加・編集する
2. `node scripts/medops/build.mjs` を実行する(全ページ再生成 + sitemap更新)
3. `node scripts/check-site.mjs` で機械検査
4. `ship` スキルに従って出荷

- `status: 'draft'` のテンプレート・記事はページ生成も一覧表示もされない(憲法第14条)。
- 公開コンテンツが1件もないカテゴリのページは生成されない。
- slugを変更した場合、旧slugのディレクトリは自動削除されない。`git status` で確認して手で消すこと。

## 設計判断のメモ

- **生成方式** — コンテンツ量が多いため、データ駆動でHTMLを生成してコミットする。公開物は純粋な静的ファイルで、既存の「ビルドなし」方針を崩さない。
- **正直さの担保** — 決済は未実装のため「決済準備中」を明示(準備中を販売中に見せない)。ダウンロード数・評価など実測していない数値は持たない。並び順は「人気順」ではなく「おすすめ順」(`priority`)。
- **検索** — 独立した検索ページは作らず、ヘッダー検索 → `templates/index.html?q=` で
  テンプレート絞り込み + 記事の横断表示。件数が増えたら専用ページ化を検討。
- **料金ページ** — ナビ・フッターに載せない(買えないプランを入口に置かない)。導線はテンプレート詳細と「初めての方へ」から。
- **有料商品** — 初回公開は代表パック1本のみ。残り9パックは実務素材の裏付けを整えてから公開する(data上はdraft)。

## 実ファイル(Excel/Word)を追加するとき

1. `medops/files/<slug>/` にファイルを置く(現状このディレクトリはない)
2. `templates.mjs` の該当商品に配布用パスを持たせ、`build.mjs` の詳細ページにダウンロードUIを追加
3. 有料分は決済・認可の仕組みができるまで公開ディレクトリに置かない(静的ホスティングでは URL を知っていれば誰でも取得できるため)
