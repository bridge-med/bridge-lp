## 2. 改善案(designer opus 監査・PM 計画)

- トップ=Level1 だけ。HUD 1段6値(Day・現金・今日の患者数・今日の売上・評判・医療スコア)。速度は4ボタン(⏸/×1/×2/⏩1日。×4 以上は Day4 から)。ミッション帯は廃止し「今日の経営」1行目へ。目標 ヘッダー 223→120px 以下。順序 HUD→今日の経営→3D→ライブモニター→診療時間。
- 「今日の経営」=1〜3行(目標/進捗/タップ先)。1行目 導入行(Day1〜7)またはミッション・2行目 詰まりの打ち手・3行目 依頼。クイズは末尾チップ。既存の data-goto で1タップ到達。
- Bottom Nav 5カテゴリ: 🏥クリニック/👥スタッフ/🗺タウン/📊経営/📚学び。法人は経営内セクションに吸収。section 移設と data-tab の書き換えだけ(カード id・セーブ不変)。ナビの表示日 Day1 クリニック/Day2 学び/Day4 タウン・スタッフ/Day8 経営。unlockStage の 1/2/3 は不変。
- 導入シナリオ Day1〜7 は別配列 ONBOARD(7件・操作の指示)。MISSIONS(結果の達成・報酬)には触れない。TUTORIAL 5段モーダルは廃止。既存セーブは step=7 で導入を出さない。
- 重要イベント: 1日1モーダル(解放>分岐点>結果)。「昨日の結果」カードを常設(3行+くわしく)。達成はバナー5秒。購入はトースト。バナーとモーダルの同時表示禁止。
- 経営判断カード: 費用/効果/リスクの3行型(数値は既存の算出から。測れないものは「まだ判定できない」)。🔒個別行→「Day4 で3つ開きます」1行。
- デザイン: Level1=--blue-pale 地+左4px 濃藍/Level2 白カード/Level3 枠なし。HUD 数値 20px/700。--amber は「今日の経営」の現在行と分岐点だけ。3D ステージをカード枠から出す。新色なし。

## 4. デザイン系(便AN・社長決裁 2026-09-12)

社長の指摘「UI を良くするというところに絵文字を入れればってわけじゃない。既存デザインに固執しすぎでは」→「憲法とは別のものを認める。良いものにしたいから」。モック3案(A 現行の延長/B ゲームUI 板とパネル/C 3D主役+オーバーレイHUD)×3画面から「B.C.B」=トップ B・タウン C・経営判断 B。

- トークン(B): 地 #E9EFF2・板 #FFF+下辺 2px #C8D6DE・文字 #1B2C36/#45585F/#53656D・決断 #2C5F82・お金 #7D5A12・警告 #A93F36・良い結果 #286B55・線 #D4DFE5・角丸 12・影 0 4px 10px。文字色は実際の地色の全組合せで 4.5:1 以上。書体 Zen Kaku Gothic New+Roboto Mono(数字は等幅)。
- 意味色の規則: 藍=これから押す(決断)・金=お金・赤=警告・緑=結果として良い。塗りは1画面の主アクション1つまで。色面は1画面2つまで。グラデ・光沢なし。
- アイコン: 絵文字を使わない。線画 SVG 1系統(app/ui/icons.js・24 viewBox・線幅1.75)。源流は `<i data-ic="name">`、描画済み DOM の絵文字は掃除で置換(対応表にない絵文字は除去して console に記録)。
- 3D 視察(v96): 写実でなく「クリニックとして読める密度」。天井と壁で閉じる・床材で部屋を示す・浮くラベルは壁付けサイン・什器は箱の組合せ・人物は足元のブロブ影・院内の光は天気で暗くしない。外部モデルは持ち込まない。
- 憲法との関係: 外れてよい条=第22〜24条。守る条=第8・15条・第19条3〜4号・44px/AA・スマホ最優先・文字量・三分法。未決事項#8。
