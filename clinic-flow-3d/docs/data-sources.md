# 診療報酬データの出典

ゲーム内の点数・算定条件・施設基準・併算定ルールの一次データは、リポジトリ内の
**medical-kb**(令和8年度診療報酬Knowledge Base)に由来する。

```
medical-kb/data/kb/r08/*.json   … 正規データ(告示・通知の原文引用evidence付き)
        │  node medical-kb/scripts/build_game_pack.mjs
        ▼
clinic-flow-3d/data/kb-r08.js   … ゲームパック(生成物。手で編集しない)
```

## 一次資料(medical-kb/data/manifest/sources.r08.json に全55文書の台帳)

- 診療報酬の算定方法の一部を改正する件(令和8年厚生労働省告示第69号)別表第一 医科点数表
- 診療報酬の算定方法の一部改正に伴う実施上の留意事項について(令和8年3月5日 保医発0305第6号)
- 基本診療料/特掲診療料の施設基準等(告示第70号・第71号)と届出手続き通知(保医発0305第7号・第8号)
- 疑義解釈資料(その1〜その11)、医科診療行為マスター、医科電子点数表(支払基金)ほか

各点数はPDF実物の原文引用+医科診療行為マスターとの突合済み(evidence参照)。
レシートの算定詳細から出典(文書名・ページ・原文)を確認できる。

## KB未登録(「概算」表示)の項目

回復期病棟入院料・検体検査の実施原価等、モジュールが原価側で持つ概算のみ。
v40で手技側(G010・L104・J000-1・J122-2・J119-2・H003-2)、v43で神経ブロック(L100-2)・
エコー(D215)・MRI一式(E202-2/E203/電子画像管理)・体制加算(時間外対応体制・明細書発行体制等。
外来後発はR8で廃止・再編のため削除)、v45で材料(ダイアライザー)、v47で薬剤
(関節注入=アルツ66点・トリガー/ブロック=キシロカイン5点/11点。散瞳剤は15円以下で
算定しない=否定的確認)を解決し、本院整形の点数行は全てKB実点数。

## 更新方法

改定・追加登録時は medical-kb 側を更新(docs/update-guide.md)し、build_game_pack を再実行、
出荷する。sw.js は network-first(常に最新を取り、オフライン時だけキャッシュ)のため、KB更新で VER を上げる
必要はない(VER はキャッシュの形を変えたときだけ上げる)。ゲーム側コードの点数修正は発生しない(発生したら設計違反)。
