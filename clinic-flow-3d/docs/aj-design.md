## 4. 扉への入口

**推奨 = 科カードの「後」。** リード文 → 科カード → レーン2択(小) → 開始ボタン。

- 扉の主題は「どの院を継ぐか」(v66)。最初の問いを2つに割ると主従が消える(第27条=同じ顔の分岐を並べない)。
