# わたしのAIパートナー

一緒に、やりたいことを見つけていくためのAI環境です。

## これは何？

あなた専用のAI相棒が住んでいる場所です。

- やりたいことがまだ決まっていなくても大丈夫。話しているうちに一緒に見つけていきます
- 副業・note・X・文章づくり・AIの使い方など、気になったことを何でも相談できます
- 話した内容のうち大事なことは、この場所に少しずつ記録されて、次の会話に活きます

先生でもコンサルタントでもなく、「話しやすい、少し詳しい相棒」だと思ってください。

## はじめかた（3通り）

**A. WEBアプリで使う（URLを開くだけ・スマホ可）**
https://bridge-med.jp/my-ai-partner/webapp/ を開く。
初回だけ「設定」でAPIキー（AIの鍵）を貼れば、以後はブックマークから開くだけ。
費用は使った分だけ（軽い利用で月数百円ほど）。鍵の作り方はアプリの設定画面に書いてある。

**B. claude.ai のプロジェクトで使う（Claude契約がある場合）**
ブラウザやアプリで claude.ai を開き、「わたしのAIパートナー」プロジェクトの中で話しかけるだけ。
セットアップは `claude-project/SETUP.md` の手順で10分（管理者が1回やれば以後は開くだけ）。

**C. Claude Code でこのフォルダを開いて使う（記憶がファイルに残る上位版）**
Claude Code（AIとの対話画面）を開いて、話しかけるだけです。
特別な言葉や命令は要りません。ふだんの言葉で大丈夫です。

最初のひとことに迷ったら、こんな感じで：

- 「副業をやってみたいけど、何が自分に合っているか分からなくて」
- 「noteってどうやって書くの？」
- 「AIって何ができるのか教えてほしい」
- 「なんとなく話を聞いてほしい」

## この場所に何が入っているか

| フォルダ | 中身 |
|---|---|
| profile/ | あなたについての記録（あなたが話したことだけが入ります） |
| ideas/ | 「これいいかも」と思ったことのメモ置き場 |
| work/ | noteの記事やXの投稿など、作っているもの |
| knowledge/ | AIが答えるときに参照する教科書（読まなくて大丈夫です） |
| agents/ | AIの仕事の手順書（読まなくて大丈夫です） |

## 安心してほしいこと

- AIがあなたの目標や進む方向を勝手に決めることはありません
- 「やってみたけど合わなかった」は失敗ではなく、大事な発見として扱います
- 「簡単に稼げる」といった話はしません。うまい話には一緒に慎重になります
- 記録されるのは、あなたが自分で話したことだけです

## 費用について

この環境自体は無料です。ただし、AI（Claude）を使うこと自体に利用料がかかります
（有料プランの月額、または使った分だけの従量課金）。
このほかに料金が発生するもの（有料ツールなど）をAIが提案するときは、必ず金額を伝えます。

## 気をつけること

- この場所には、本名・住所・勤務先など、個人が特定される情報を書き残さないようにしています
- パスワードやクレジットカード番号は、AIとの会話でも入力しないでください
