# profile/ — 記憶のルール

利用者についての記録。ここが正確であるほど回答の質が上がるが、
**間違った思い込みを固定することが最大の害**になる。少なめ・確実を優先する。

## 記録してよいもの（この3つだけ）

1. 本人が明言したこと（例：「文章を書くのは好き」「顔出しはしたくない」）
2. 複数回の会話で明確になったこと（例：毎回動画の話題を避ける → 動画は気が進まない様子、と**出どころ付きで**）
3. 本人が選択したこと（例：A/B/C案からBを選んだ）

## 記録してはいけないもの

- 性格診断・人物像の推測（「慎重な性格」などの断定）
- 向いている仕事の断定
- 収入状況・家計の推測
- 家族関係・交友関係の推測
- 本名・住所・勤務先など、個人が特定される情報（会話に出ても記録しない）

## 保存の基準

保存するのは「**今後の回答が変わる情報**」だけ。

- 「寿司食べたい」→ 保存しない
- 「料理系の発信をやってみたい」→ 保存候補
- 「平日は夜1時間くらいしか時間がない」→ 保存候補（constraints.md）
- 「動画編集やってみたけど面倒だった」→ 保存候補（dislikes.md）

迷ったら保存しない。あとで本人がまた言ったら、そのとき保存すればいい。

## 書き方

- 各ファイルに日付付きの箇条書きで追記する。例：`- 2026-08: 料理系の発信に興味あり（本人談）`
- できるだけ本人の言葉のまま書く。言い換えで意味を変えない
- 変わったことが分かったら、古い記録を消さず「→ 2026-10: 考えが変わり、○○に」と更新する
- 保存・更新をいちいち本人に報告しない。聞かれたら見せる（本人のものなので隠さない）

## ファイルの役割

| ファイル | 中身 |
|---|---|
| basics.md | 基本情報（呼ばれたい名前、生活リズムなど本人が話した範囲） |
| interests.md | 興味があること・気になっていること |
| preferences.md | 好みのやり方（文章の雰囲気、教わり方、ペースなど） |
| dislikes.md | 苦手・避けたいこと・「合わなかった」こと |
| strengths.md | 得意なこと・経験があること（本人談のみ） |
| constraints.md | 使える時間・環境・条件（顔出しNGなど） |
| goals.md | 本人が言葉にした目標・方向性 |
| progress.md | 大きな一歩の記録（マイルストーンのみ。日記化しない） |
