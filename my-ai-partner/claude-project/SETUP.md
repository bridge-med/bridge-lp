# セットアップ手順（管理者向け・所要10分）

奥さんのスマホ／PCのブラウザだけで使える形にする手順。プログラミングは一切不要。

## 用意するもの

- 利用者本人の claude.ai アカウント（無料プランでも動くが、プロジェクト機能と利用量の面で **Proプラン推奨**。料金は claude.ai で要確認）
- 教科書のWordファイル3冊（このリポジトリの元になった `01_AIアシスタント運用基盤` / `02_AI初心者・活用ナレッジ` / `03_note・X・副業実践ナレッジ`）
  - 手元にWordが無い場合は `my-ai-partner/knowledge/textbook/` の .md ファイル一式でも可

## 手順

1. 利用者のアカウントで claude.ai にログインする
2. 「プロジェクト」を新規作成 → 名前を **わたしのAIパートナー** にする
3. プロジェクトの **「指示」欄** に、`instructions.md` の区切り線から下を全文コピーして貼り付ける
4. プロジェクトの **「知識」** に、教科書3冊のファイルをアップロードする
5. 設定にメモリ（過去の会話を覚える）機能があればオンにする
6. 動作テスト。プロジェクト内で新しいチャットを開き、次を送って確認する：
   - 「副業をやってみたいけど、何が合うか分からなくて」→ 質問攻めにせず、まず答えてから聞き返しが1つだけなら合格
   - 「noteって稼げますか？」→ 煽らず「時間がかかるのが普通」と正直に答えたら合格

## 使うときの入口（ホーム画面に追加しておくと親切）

- スマホ：claude.ai アプリを入れる → プロジェクトを開く → 話すだけ
- 会話は毎回「プロジェクトの中で」始めること（プロジェクト外だと教科書が効かない）

## 制約（正直に）

- この形では、リポジトリの profile/（記憶ファイル）への自動記録は動かない。会話メモリ機能がその代わりになる。より確実に残したいことは、本人が「これ覚えておいて」と言う運用でよい
- note記事の下書きなどの成果物は、チャットからコピーして note に貼る運用になる
- リポジトリ版（Claude Code で開く形）は、ファイルに記憶が残る上位版としてそのまま残っている。将来、専用アプリ（チャット画面）を作る場合の土台も同じ

## 困ったとき

- 返事が教科書と違う雰囲気になる → プロジェクト内で会話しているか確認。指示欄が空になっていないか確認
- 「知識の容量オーバー」と出る → Word版ではなく `knowledge/textbook/` の .md（軽量）でアップロードし直す
