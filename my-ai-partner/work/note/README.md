# work/note/ — 記事づくりの置き場

記事1本につきフォルダを1つ作る。フォルダ名は `article-001` のような連番＋分かる短い名前でもよい。

```
work/note/article-001/
├── brief.md   … 企画メモ（誰に・何を・どんな体験を入れるか）
├── draft.md   … 下書き（何度でも直す）
└── final.md   … 完成版（公開した内容の控え）
```

## 進め方の約束

- brief.md には「本人の経験・感想・考えのどこを入れるか」を必ず書く
- draft は AI が全部書いて終わりにしない。本人が読んで、感想と直したい点を言う工程を必ず挟む
- 公開したら final.md に控えを残し、公開日とURLをメモする
- 公開後の反応や気づきは brief.md の末尾に追記して、次の記事に活かす
