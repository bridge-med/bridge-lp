# アプリのはじめかた（管理者向け・初回だけ15分）

ブラウザで動くチャットアプリ。AIの呼び出しは**このパソコンの中のClaude Code**が行うので、
APIキーの発行や追加の従量課金は不要（Claudeの契約＝サブスクの範囲内で動く）。
会話から分かった大事なことは、AIが profile/ などのファイルに実際に書き残していく。

## 初回セットアップ（利用者が使うパソコンで1回だけ）

1. **Node.js** を入れる — nodejs.org から「LTS」をダウンロードしてインストール
2. **Claude Code** を入れる — ターミナル（Windowsはコマンドプロンプト）で
   `npm install -g @anthropic-ai/claude-code`
3. **ログイン** — ターミナルで `claude` と打ち、画面の案内でClaudeアカウントにログインして終了
4. **このフォルダを配置** — `my-ai-partner` フォルダごと、分かりやすい場所（例：書類フォルダ）へコピーする
   ※BRIDGEのリポジトリの外に置くこと（他プロジェクトのルールが混ざらないようにするため）

## ふだんの起動（利用者がやること）

- Mac: `app/start.command` をダブルクリック
  （初回に「開けません」と出たら: 右クリック→開く。またはターミナルで `chmod +x start.command` を1回）
- Windows: `app/start.bat` をダブルクリック

→ 黒いウィンドウが開き、続けてブラウザで画面が開く。あとは話しかけるだけ。
終わるときはブラウザを閉じて、黒いウィンドウも閉じる。

デスクトップにショートカットを作っておくと、奥さんは「アイコンをダブルクリックするだけ」になる。

## 費用

- 追加費用なし。Claudeの契約（Pro等）の利用枠を使う。使いすぎると他のClaude利用と同じく上限に当たることはある

## 記憶とデータ

- 会話で分かった大事なこと → AIが `profile/` に記録（本人が明言したことだけ。ルールは profile/README.md）
- アイデア → `ideas/`、記事の下書き → `work/`。すべてこのフォルダ内のファイルで、外部には送られない
- 画面の「＋新しい会話」は話題のリセット。ファイルに残した記録は消えない

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| 「AIへの接続に失敗」と出る | ターミナルで `claude` と打ってログインし直してから再起動 |
| 「Claude Codeが見つかりません」 | 手順2を再実行。会社PC等でnpmが使えない場合は管理者権限を確認 |
| 画面が開かない | ブラウザで http://127.0.0.1:8737 を直接開く |
| 返事が遅い | 初回や長い相談は1〜2分かかることがある。黒いウィンドウを閉じない |
