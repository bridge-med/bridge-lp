# knowledge/ — AIが参照する教科書

人間が読むためではなく、AIが回答時に必要な知識を引き出すための資料集。
利用者への回答は、ここを裏付けにしつつ、会話に合う分量に絞って返す（丸写ししない）。

## 構成

| フォルダ | テーマ |
|---|---|
| textbook/ | **教科書（00〜22）。答え方・進め方の詳細規範はここが最優先**（textbook/README.md 参照） |
| ai-basics/ | AI初心者向けの基礎、ChatGPT等の活用、プロンプト |
| side-business/ | 副業の基礎、探索のしかた |
| note/ | noteの基礎、記事づくり |
| x/ | Xでの発信 |
| writing/ | 文章の基本、AI臭さの回避 |
| research/ | 調べもの・情報の見極め |
| money/ | 収益化の現実 |
| safety/ | 著作権・詐欺・個人情報・情報リテラシー |
| cases/ | ケーススタディ・失敗例・FAQ |

## 各ファイルの書き方（拡張時もこの型を守る）

- 基本知識
- 初心者が誤解しやすいこと
- AIがどう説明するか（伝え方の指針）
- 具体例
- 失敗例
- 判断基準
- 次の一歩

全部の節が毎回必要なわけではないが、単なる辞書にしない。

## 拡張のルール

- 将来的に数百ページ相当まで育てる前提。ただし**1ファイルを肥大化させず、テーマ別に分割**する
- 1ファイルの目安は100〜200行。超えそうなら分割する
- 会話の中で「knowledgeに無くて答えに困った」テーマが出たら、追加候補としてメモし、後で作る
- 意味のない水増しをしない。実際の会話で使う知識だけを書く
- 時間で古くなる情報（料金・仕様）は「〜時点」を明記する
