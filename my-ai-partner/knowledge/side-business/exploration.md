# 副業探索のしかた

## 基本の流れ

1. 会話から材料を集める（一度に聞かない。agents/discovery.md 参照）
2. 2〜3候補に絞る
3. 候補ごとに「最小の実験」を設計する
4. 実験 → 感想を聞く → 続ける／変える／やめるを本人が決める
5. 分かったことを profile/ に残す

## 候補を見る10の観点

| 観点 | 見るポイント |
|---|---|
| 興味 | 話していて声が乗るか |
| 経験 | 過去の仕事・趣味・生活とつながるか |
| 初期コスト | 道具・登録料・仕入れが要るか |
| 継続負荷 | 週に何時間、どんな作業が続くか |
| 顔出し | 必要か。避ける方法はあるか |
| 必要時間 | 成果が見えるまでの見込み |
| 収益化までの距離 | 最初の1円までの遠さ |
| 競争 | 同じことをしている人の多さ |
| 学習量 | 新しく覚えることの量 |
| 楽しさ | 収益ゼロでも続けたいと思えるか |

点数化してもよいが、数字だけで決めない。最後は本人の「やってみたい」。

## 最小の実験の設計

- **小ささ**：週2時間×2〜4週で終わる規模。例：note→無料記事1本、X→3投稿、ハンドメイド→3作品
- **終わりを決める**:「○本作ったら一度ふりかえる」と先に決める。だらだら続けない
- **測るもの**：数字（閲覧数など）より先に「やっていて楽しかったか・無理がなかったか」
- 道具を買うのは実験の後。実験は手持ちのもので

## 「やめる」の扱い

- 実験して「合わない」は成功（合わないことが分かった）。profile/dislikes.md に何が合わなかったか（作業内容？時間？人とのやり取り？）まで書くと、次の候補選びが速くなる
- 3回連続で「合わない」が続いたら、候補の出し方自体を変える（分野ではなく作業の種類で考える等）

## 初心者が誤解しやすいこと

- 「最初の選択で人生が決まる」→ 決まらない。実験は何度でもできる
- 「途中でやめるのは根性がない」→ 実験の設計どおり。データが取れた
- 「全部の観点で高得点の副業がある」→ ない。何を優先するかを決めるだけ
