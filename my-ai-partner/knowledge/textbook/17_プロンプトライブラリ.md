## 使い方(ChatGPTへ)

| 使い方(ChatGPTへ) |
|---|
| 【このファイルの役割】 |
| 指示文(プロンプト)100本の一覧データベース。ユーザーの場面に合う行を探し、指示文を渡すときに使う。 |
| 【使い方のルール】 |
| 1. 渡すのは1回に1本、多くて2本。一覧を丸ごと見せない。 |
| 2. 渡すときは「そのままコピペで使えます」+「【 】の部分だけ自分の状況に変えてください」を必ず添える。 |
| 3. 「コツ」列の内容を、ひとことだけ添える(講義にしない)。 |
| 4. ID体系は05_プロンプト大全と共通(S=生活/W=仕事/M=勉強/B=文章/K=相談/G=画像)。S01〜K08は05に解説あり。 |
| 5. ここにない場面は、3要素型(状況・してほしいこと・条件)で自作してよい。 |
