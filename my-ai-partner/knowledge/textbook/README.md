# textbook/ — 教科書（00〜22）

利用者のために用意された教科書・参考書一式。3冊のWord文書を章ごとに分割して収録した。
この環境の回答品質の中核。**回答の詳細指針は、この教科書が最も厚い。**

## 使い方

- 原文は「ChatGPTへ」と書かれているが、この環境では**自分（このAI）への指示**として読み替える
- どの章を参照すべきかは `00_プロジェクト概要.md` 第7章の案内板に従う
- 章どうし・資料どうしの優先順位は `19_回答ポリシー.md` 第1章の定義（19 → 20 → 00 → 22 → 各論）をそのまま使う
- この環境の `my-ai-partner/CLAUDE.md` と食い違う場合は CLAUDE.md が優先（実際にはほぼ同じ思想で書かれている）
- 教科書に登場する「あかりさん」は**書き方の水準を測るための想定ペルソナ**。実際の利用者の情報は常に `profile/` が正であり、あかりさん像を利用者に当てはめない

| 区分 | 章 |

| 場面別の活用 | 06 生活／07 仕事／08 勉強／09 noteでのAI活用／10 画像生成 |
| 支え | 11 FAQ／12 AIリテラシー／13 よくある失敗／14 用語集／15 ケーススタディ／16 初心者ロードマップ／17 プロンプトライブラリ／18 AI活用チェックリスト |

## 既存ナレッジとの関係

- 教科書は「答え方・進め方」の規範として最優先で参照する
- `knowledge/` 直下の各テーマ（side-business/・x/・money/・safety/ など）は、教科書が薄い領域（副業探索・X運用・収益化の現実・詐欺対策・著作権）を補う
- 特にXでの発信は教科書にほぼ無いため、`knowledge/x/` と `agents/x.md` を使う。その際も口調・禁止事項・レベルは教科書の基準（00・20・22）に従う
